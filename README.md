
"""
============================================================
                     JARVIS AI ASSISTANT
============================================================

PROJECT DESCRIPTION:
Jarvis is a Python-based voice assistant designed to perform
everyday computer tasks through voice commands and provide
AI-generated responses using the Google Gemini API.

MAIN FEATURES:
1. Voice Interaction:
   Listens to voice commands and responds using text-to-speech.

2. Wake Words:
   Can be activated using supported wake words such as
   "Hey Alpha", "Alfa", or "Jarvis".

3. Website Access:
   Opens supported websites, including Google, YouTube,
   Facebook, Instagram, and LinkedIn.

4. Music Playback:
   Plays music using the tracks and commands configured
   in the project's music library.

5. News Updates:
   Retrieves top news headlines using the NewsAPI service
   and reads them aloud.

6. Desktop Applications:
   Can launch supported applications such as Notepad,
   Google Chrome, and Visual Studio Code.

7. AI-Powered Responses:
   Uses the Google Gemini API to answer general questions
   that are not handled by the predefined voice commands.

HOW TO USE:
- Say "Hey Alpha", "Alfa", or "Jarvis" to activate the
  assistant, depending on the wake-word logic in the code.
- Say "Open Google" to open Google.
- Say "Open YouTube" to open YouTube.
- Say "Open Facebook" to open Facebook.
- Say "Open Instagram" to open Instagram.
- Say "Open LinkedIn" to open LinkedIn.
- Say "Open Notepad" to launch Notepad.
- Say "Open Chrome" to launch Google Chrome.
- Say "Open VS Code" to launch Visual Studio Code.
- Say "News" or the configured news command to hear
  the latest headlines.
- Say "Play [song name]" or the supported music command
  to play a track configured in the music library.
- Ask a general question to receive an AI-generated answer.
- Use the deactivation command defined in the code to
  stop or deactivate the assistant.

REQUIREMENTS:
- Python and the project's required Python packages.
- A working microphone and speakers.
- An internet connection for online speech recognition,
  Gemini AI responses, and news retrieval.
- Valid API keys for the services used by the project.
- Correct application paths and a properly configured
  virtual environment.

SECURITY AND PRIVACY:
- API keys and other credentials must remain private.
- Never share or upload the .env file.
- Keep private configuration files and personal data secure.
- Do not include the virtual environment in public uploads.
- Use a .gitignore file to exclude sensitive files,
  virtual environments, and generated cache files.

IMPORTANT:
The exact commands and available features depend on the
conditions, website mappings, music library, and application
paths configured in the source code.

============================================================
"""
